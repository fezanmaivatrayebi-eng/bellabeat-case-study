# Étude de cas Bellabeat — Analyse de données de fitness connectées

## Contexte
Bellabeat souhaite comprendre les tendances d'utilisation des objets connectés
de fitness afin d'identifier des opportunités de croissance et d'orienter sa
stratégie marketing.

## Données
Jeu de données FitBit Fitness Tracker Data (licence CC0, via Kaggle),
33 utilisateurs, données d'activité quotidienne et de sommeil.

## Méthodologie
Nettoyage et fusion des données avec Python (pandas), analyse descriptive
et corrélationnelle, visualisation des résultats.

## Résultats clés
- 8 515 pas quotidiens en moyenne
- 72,7% du temps quotidien passé en position sédentaire
- 419 minutes de sommeil en moyenne
- Corrélation faible entre activité et sédentarité

## Recommandations
1. Encourager des pauses actives régulières
2. Mettre en avant le suivi du sommeil comme argument clé
3. Personnaliser les recommandations selon le profil d'activité

## Outils utilisés
Python, pandas, matplotlib, Jupyter
